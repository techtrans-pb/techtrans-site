# 2. こんな相談から始まります

AIについて相談したい。  
でも、何を頼めばよいのかは、まだ決まっていない。

それで構いません。

- 社員がAIを使い始めたが、使い方に差がある
- AIを仕事で使いたいが、どこから始めればよいか分からない
- 今の使い方が本当に効率化につながっているか確認したい
- 特定の業務をAIで改善できるか試したい
- AIを仕組みに組み込みたい
- AIで作った資料を、そのまま外に出してよいか不安
- 研修、業務改善、開発のどれが合うのか分からない

**最初に商品を決めるのではなく、御社の業務を見て、最も効果の出る方法を一緒に考えます。**

# 5. AI実務活用教育

## AIの使い方を教える講座ではなく、各職種の仕事をAIで改善する技能を身につける講座。

TriTransのAI実務活用教育では、  
AIツールの操作方法やプロンプトの型だけを学ぶのではありません。

事務、営業、新規事業など、受講者が実際に担当する職務に合わせて、  
**その職務で多くの企業に共通する業務・作業を題材に、生成AIを活用する技術を学びます。**

事務職であれば、文書作成、集計、確認、情報整理。  
営業職であれば、ニーズ整理、議事録、提案書作成。  
新規事業であれば、調査、比較、仮説整理、企画作成。

こうした職務に直接関係する業務でAIを使い、  
作業時間を短縮しながら、確認・修正を通じて成果物の品質を高める技術を身につけます。

# 6. AI実務活用研修｜個社導入コース

## AIを学ぶ研修ではなく、御社でAIを使い始めるための15時間講座。

### 研修前に、会社と受講者の仕事を確認します

研修前に経営者・経営陣と面談し、  
受講者の担当職務と必要な業務スキルを確認します。

その職務に対応するAI活用スキルを整理し、  
**会社別のゴールと、受講者ごとの実務テーマを設定します。**

### 実務に近い題材で学びます

通常業務と区別したOFF-JT形式で、3時間×5回、計15時間実施します。

実際の業務に近い題材を使いながら、  
受講者自身が演習し、AIの出力を確認・修正する訓練として進めます。

研修の中で会社の業務を講師が代行するのではなく、  
**受講者自身がAIを使えるようになること**が目的です。

### 研修で身につけること

- 生成AIの特性と限界を理解する
- 情報をAIに渡せる形へ整理する
- 目的・条件・制約を言葉にする
- AIへの指示を改善する
- 文書・資料・説明案を作る
- 複数案を比較する
- 原資料と照合する
- 抜け漏れや誤りを確認する
- AIの出力を修正する
- 情報入力時の安全性を判断する
- AIに任せる部分と、人が判断する部分を分ける
- 自分の職務で次に試すテーマを整理する

### 受講後に目指す状態

**研修後も、自社でAIを使い続けられることを大切にしています。**

受講後は、AIを使って小さな業務課題を自力で前へ進められる状態を目指します。

会社には、

- AIを安全に使える人材
- 自社で試すAI活用テーマ
- 利用上の注意点・確認手順
- AI活用を継続するための考え方

が残るように設計します。

# 8. 経営者向けAI実務体験

## AIを社員に任せる前に、まず経営者から。

経営者ご自身がAIの手応えと限界を知ることで、  
どの仕事に使い、どこを人が判断するかの線引きがしやすくなります。

全社導入や社員研修とは切り離し、  
短時間で実務体験に絞ります。

**いちばん忙しい人が、いちばん先に使うと、会社は変わる。**

### 料金（税抜）

- 1日コース｜3時間｜90,000円
- 2日コース｜3時間×2回｜150,000円

# 9. オーダーメイド研修

## 既存コースに当てはまらない場合も、ご相談ください

**その他、企業様の業務内容・対象者・目的に応じたオーダーメイド研修も承ります。**

既存のコースに当てはめるのではなく、  
職種、業務課題、AI活用状況、受講人数を確認し、必要に応じて研修内容を個別に設計します。

**「この内容で研修できるだろうか」という段階でもご相談ください。**

対象例：

- 特定部門向けのAI実務研修
- 管理部門・営業部門向けの職種別研修
- 新規事業・企画部門向け研修
- 既にAIを使っている社員向けの実務高度化研修
- 社内ルール・安全利用と組み合わせた研修
- 少人数の集中研修
- その他、業務内容に応じた個別設計

**料金：内容・人数・実施時間に応じて個別見積**
