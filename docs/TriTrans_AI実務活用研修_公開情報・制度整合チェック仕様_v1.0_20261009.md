# TriTrans AI実務活用研修｜公開情報・制度整合チェック仕様 v1.0

作成日：2026-10-09  
用途：LP・パンフレット・申込資料・実施資料の整合確認用  
公開区分：内部管理  
注意：本書は助成金の支給を保証するものではない。最終的な適用判断は受講企業の状況、訓練計画、対象労働者、申請内容等を含め管轄労働局が行う。

---

# 1. 基本原則

TriTransの研修は、助成金に合わせて作るのではない。

実際の職務で必要なAI活用技能を習得する教育として設計し、その実態・価格・時間・内容・証跡を正確に公開・記録する。

対外営業では助成制度を前面に出さない。

一方、制度確認時に、

- 何の講座か
- 誰でも申し込める通常の商品か
- 価格はいくらか
- 何時間か
- 何を学ぶか
- 職務とどう関係するか
- 通常業務と区別された訓練か
- 誰が教えるか
- 実施記録があるか

を説明できる状態を維持する。

---

# 2. 厚生労働省の現行制度から確認しておく事項

## 2.1 事業展開等リスキリング支援コース

制度側では、新規事業等の事業展開、デジタル・DX化、グリーン化等に伴い、新たな分野で必要となる知識・技能を習得させる訓練が対象となる。

基本要件として、OFF-JTであること、実訓練時間数10時間以上等が示されている。

TriTrans個社導入コースは15時間で設計する。

---

## 2.2 OFF-JT

通常の生産活動・就労の場と区別できない実務作業は避ける。

顧客業務に近い題材を用いる場合でも、

- 受講者本人が演習する
- 技能習得が目的
- 通常業務の完成・納品を目的にしない
- 講師が業務代行しない

ことを明確にする。

---

## 2.3 講師

専門的知識・技能を持つ講師による訓練であることを説明できるよう、講師略歴・実務経験・担当領域を内部資料として整備する。

LPでも代表・講師の実務背景を適切に表示する。

---

## 2.4 価格

公開通常価格：

- 2名 900,000円（税抜）
- 3名 1,200,000円（税抜）
- 4名以降 1名追加ごとに300,000円（税抜）

助成制度の利用有無で価格を変えない。

LP、パンフレット、見積書、契約書、請求書の整合を保つ。

2026年5月14日以降、支給申請に「受講料等の価格設定に関する疎明書」が必要となる場合があるため、価格形成の説明根拠を内部で保持する。

# 3. LP公開チェック

## 商品情報
- [ ] 講座名が明示されている
- [ ] 15時間、3時間×5回が明示されている
- [ ] 2名から、最大10名が明示されている
- [ ] 価格が明示されている
- [ ] 遠方旅費の扱いが明示されている
- [ ] 申込方法がある
- [ ] 一般企業が問い合わせ・申込できる

## 教育内容
- [ ] AIの一般操作だけに見えない
- [ ] 職務に関連する技能として説明されている
- [ ] 文書作成・情報整理・比較・照合・品質確認等が含まれる
- [ ] 情報管理・安全利用が含まれる
- [ ] 人の判断・確認工程が含まれる
- [ ] 受講者本人が演習することが分かる

## 個社設計
- [ ] 経営者・経営陣との事前面談が明示されている
- [ ] 会社別ゴールを設定することが明示されている
- [ ] 受講者ごとの業務テーマを設定することが明示されている
- [ ] 個別テーマは講座本体の技能習得へ接続している
- [ ] 特定企業向け業務代行に見えない

## OFF-JT
- [ ] 通常業務と区別したOFF-JTであることを明示
- [ ] 研修時間中に通常業務の成果物完成を主目的としない
- [ ] 教育とコンサル・開発の境界を明記

## 助成金表現
- [ ] 「助成対象講座」と書いていない
- [ ] 支給率を書いていない
- [ ] 支給を保証していない
- [ ] 助成制度を価格訴求に使っていない
- [ ] 制度名を営業フックとして使っていない

# 4. パンフレットからLPへ継承する重要表現

- AIを学ぶ研修ではなく、御社でAIを使い始めるための15時間講座
- 経営者面談で目的・期待・不安を確認し、会社別ゴールを設定
- 会社共通設計と、受講者ごとの業務テーマを組み合わせる
- 3時間×5回、対面で学ぶ15時間の個社別講座
- 各回の間に補完教材とアンケートで確認
- 研修中に自社の小さな業務課題で演習
- 受講後は、AIを使って小さな課題を自力で前へ進められる人が育つこと
- AIを安全に使い、小さな業務課題へ適用できる人材
- 自社で試す業務を整理したAI活用テーマ
- 研修内で整理した利用上の注意点・確認手順

---

# 5. 追加する重要表現

> **研修前に経営者・経営陣と面談し、会社として目指す状態と、受講者が担当する業務を確認します。**

> **受講者に必要な業務スキルと、それに対応する生成AIの活用スキルを整理し、会社別のゴールと受講者ごとの実務テーマを設定します。**

> **単なるツール操作やプロンプトの暗記ではなく、実際の職務で共通して使えるAI活用技術を身につけます。**

> **通常業務と区別したOFF-JT形式で実施します。**

# 7. 今後の制度変更への対応

厚生労働省・労働局の一次情報を継続確認する。

制度変更があった場合、

1. 商品の本質を制度に合わせて変えない
2. 実務上必要な証跡・書式・説明情報を更新
3. LPの公開情報に不足が出た場合のみ追記
4. 助成金訴求へ転換しない

を原則とする。
